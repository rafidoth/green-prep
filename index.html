1. Cloud Computing
Basics (class-1) ⭐ PYQ Topic

Cloud Computing Definition: Dynamically scalable, virtualized computing resources delivered on demand over the network.

  • On-Demand Self-Service: Users provision computing capabilities (server time, network storage) automatically without human intervention from the service provider.
  • Broad Network Access: Computing resources are accessible across standard network protocols from heterogeneous client platforms (laptops, mobile phones, workstations).
  • Resource Pooling: Provider computing resources are pooled to serve multiple consumers using a multi-tenant model.
  • Rapid Elasticity: Workloads scale outward or inward rapidly to automatically match real-time demand peaks.
  • Measured Service: Resource usage is monitored, controlled, and billed based on actual consumption (utility pricing).

⭐The Six Computing Paradigms (Historical Evolution):

  1. Centralized Computing (Mainframes): All processing occurs on a single large central computer accessed by dumb terminals.
  2. Distributed Computing (Client-Server): Workloads split between local client machines and back-end database servers over a network.
  3. Cluster Computing: Multiple interconnected standalone computers working together as a single unified computing resource with shared memory or fast interconnects.
  4. Grid Computing: Geographically dispersed, heterogeneous computing systems combined into a virtual supercomputer for massive batch tasks.
  5. Utility Computing: Packaging computing power and storage as a metered service, similar to traditional public utilities (water and electricity).
  6. Cloud Computing: Modern convergence of utility computing, virtualization, and elastic distributed systems on demand.
Virtualization ⭐⭐ Common in PYQ

Virtualization: The foundational technology of cloud computing that abstracts physical hardware to run multiple isolated virtual environments on a single physical host.

  • Physical Server (Host): The underlying hardware containing physical CPUs, memory modules, storage arrays, and network interfaces.
  • Hypervisor (Virtual Machine Monitor / VMM): Software layer that manages physical hardware and dynamically allocates virtual resources:
    • Type-1 (Bare-Metal): Runs directly on host hardware for maximum performance (e.g., VMware ESXi, KVM, Xen, Hyper-V).
    • Type-2 (Hosted): Runs on top of a conventional host operating system (e.g., VirtualBox, VMware Workstation).
  • Virtual Machines (Guest VMs): Completely isolated software containers running guest operating systems and workloads (e.g., mail servers, web servers, database engines).
  • ⭐Green Computing Benefit (Server Consolidation):
    • Replaces 10–20 lightly loaded physical servers (running at only 5–15% capacity) with 1 dense physical server running at 70–80% capacity.
    • Dramatically reduces data center electricity consumption, cuts cooling demands, and lowers embodied hardware manufacturing carbon.
Service models ⭐⭐ Common in PYQ

The standard SPI cloud delivery models define who manages which layer of the technology stack:

  • ⭐IaaS (Infrastructure as a Service):
    • What is provided: Raw, dynamically scalable computing resources—virtual machines, block storage, firewalls, and network routing.
    • Management responsibility: The provider manages physical hardware, cooling, and virtualization. The client manages operating systems, middleware, runtime, and software applications (e.g., AWS EC2, Google Compute Engine, Microsoft Azure VMs).
    • Payment model: Pay-as-you-go utility pricing based on CPU hours, RAM, and gigabytes stored.
    • Green sustainability contribution: Dynamic resource elasticity prevents over-provisioning; workloads scale down automatically off-peak to prevent idle electricity waste.
  • PaaS (Platform as a Service):
    • What is provided: A pre-configured development and deployment environment (operating systems, programming runtimes, database management, web servers).
    • Management responsibility: The provider manages the entire underlying infrastructure and OS. The client manages only their custom code and data (e.g., Google App Engine, AWS Elastic Beanstalk, Heroku).
  • SaaS (Software as a Service):
    • What is provided: Fully functional, ready-to-use software applications delivered to users directly through a web browser or API.
    • Management responsibility: The cloud provider manages the entire technology stack from hardware to software updates (e.g., Google Workspace, Microsoft 365, Salesforce).
Three categories of cloud services ⭐ PYQ Topic
  1. 1. Software as a Service (SaaS): End-user applications hosted entirely in the cloud, replacing locally installed desktop software.
  2. 2. Attached Services (Plugins & APIs): Cloud-hosted services that extend and add capabilities to local desktop or mobile applications (e.g., online translation APIs, automated cloud backup plugins, continuous anti-virus definitions, document synchronization).
  3. 3. Cloud Platforms: Integrated suites of infrastructure, storage, and developer toolsets used to build, test, and host custom enterprise web applications.
Types of cloud computing ⭐ PYQ Topic

Four primary deployment models define cloud access, ownership, and governance:

  1. 1. Public Cloud: Infrastructure owned and operated by a third-party cloud service provider, delivered over the public internet to multiple organizations (multi-tenant architecture, highest cost efficiency).
  2. 2. Private Cloud: Infrastructure dedicated exclusively to a single business organization, hosted on-premises or by a third party (maximum security, strict data sovereignty, higher maintenance cost).
  3. 3. Hybrid Cloud: A combination of public and private clouds connected by standardized technology:
    • Keeps mission-critical and sensitive data in the secure private cloud.
    • Enables cloud bursting to offload non-sensitive compute spikes into the public cloud during heavy traffic.
  4. 4. Community Cloud: Shared cloud infrastructure managed jointly by multiple organizations with common regulatory, security, or mission requirements (e.g., healthcare alliances, government agencies).
Other topics listed (class-2, class-3) ⭐ PYQ Topic

⭐How Core Enabling Technologies Work Together (Spring 2026 Q1 Core):

  • Virtualization: Abstracts physical hardware into flexible, dynamic virtual resource pools.
  • SOA (Service-Oriented Architecture): Software design approach where business capabilities are modularized into independent, loosely coupled, reusable services.
  • Web Services: Standard communication protocols (REST, SOAP, XML, JSON) that allow disparate services to communicate across networks regardless of underlying operating systems.
  • Web 2.0 / Web 3.0 & Mashups: User-facing layer that aggregates data and services from multiple independent web APIs into a single interactive application.
  • Integration Pipeline: Hardware is virtualized $ ightarrow$ SOA structures software into modular services $ ightarrow$ Web Services interconnect them across the web $ ightarrow$ Mashups deliver integrated end-user applications.

⭐Data Center Network Architecture (Fall 2025 Q8c Core):

  • Core Layer: High-speed backbone switching incoming and outgoing data traffic between data centers and the public internet.
  • Aggregation Layer: Middle tier linking access switches, providing load balancing, routing policies, and firewall protection.
  • Access / Edge Layer (Top-of-Rack / ToR Switches): Direct network connection point for servers located within each equipment rack.

2. IoT (Green IoT)
Green IoT (class-18) ⭐⭐⭐ Top PYQ Favorite

Green IoT Definition: Designing, deploying, and operating Internet of Things (IoT) devices, networks, and data infrastructure with minimal energy consumption and carbon emissions, while using IoT data to eliminate waste in other industries.

  • Core Objectives:
    • Minimize greenhouse gas emissions across the full sensor lifecycle.
    • Design ultra-low-power microcontrollers and low-power radio communication protocols.
    • Reduce toxic e-waste by replacing chemical batteries with ambient energy harvesting.

⭐Three High-Yield Real-World Applications (Exam Favorites):

  1. 1. Smart Agriculture (Spring 2025 Q8):
    • Implementation: Deploying soil moisture, temperature, and nitrogen-phosphorus-potassium (NPK) sensors across farming plots.
    • Sustainability Impact: Enables automated precision drip irrigation and targeted fertilizer delivery; reduces agricultural water consumption by up to 50% and prevents groundwater contamination.
  2. 2. Smart Cities (Summer 2025 Q7):
    • Energy: Adaptive street lighting using motion and ambient light sensors to dim LEDs during empty hours.
    • Water Management: Acoustic and flow sensors detecting underground pipe leaks instantly before millions of liters are wasted.
    • Waste Management: Ultrasonic fill-level sensors in trash containers optimizing municipal garbage truck pickup routes, reducing diesel fuel consumption and emissions.
  3. 3. Smart Campuses & Buildings (Spring 2026 Q2):
    • Implementation: Deploying IoT passive infrared (PIR) occupancy sensors and ambient light sensors across classrooms and halls.
    • Sustainability Impact: Automatically powers down lighting and heating/air-conditioning (HVAC) systems when rooms are vacant, lowering campus electricity bills by 30–40%.
Intro to wireless technology ⭐ PYQ Topic

Three Foundation Pillars of Wireless Sensor Networks (WSNs):

  • 1. Embedded: Ultra-compact processing and storage hardware embedded directly inside physical objects and environments.
  • 2. Networked: Interconnected nodes communicating wirelessly via low-power protocols (Zigbee, 6LoWPAN, LoRaWAN, BLE).
  • 3. Sensing: Continuous monitoring of physical conditions (temperature, humidity, pressure, acoustic signals, chemical presence).

⭐Multi-Hop (Hop-to-Hop) Routing vs. Direct Transmission:

  • Direct Communication: Nodes near the central gateway transmit data packets directly over short distances.
  • Hop-to-Hop Routing: Distant nodes route packets through intermediate neighboring nodes in short steps.
  • Energy Advantage: RF transmission power increases exponentially with distance ($P \propto d^2$ in free space, $d^4$ with obstacles); multi-hop routing preserves battery life by replacing one long transmission with multiple low-power hops.
Terms (class-19) ⭐ PYQ Topic

Key IoT Architectural Concepts:

  • Ad-hoc Networking: Decentralized wireless networks that self-configure dynamically without pre-existing fixed infrastructure or central access points.
  • MEMS (Micro-Electro-Mechanical Systems): Microscopic systems combining electrical circuitry and mechanical sensors (accelerometers, gyroscopes, pressure diaphragms) fabricated on a single silicon chip.
  • NEMS (Nano-Electro-Mechanical Systems): Molecular-scale electromechanical devices offering atomic-level sensitivity, extreme miniaturization, and ultra-low power consumption.

⭐Core Green IoT Power Optimization Techniques (Exam Essentials):

  • Duty Cycling: Scheduling sensor nodes to stay in ultra-low power sleep mode for 90%–99% of the time, waking up for milliseconds only to sample and transmit readings.
  • Energy Harvesting: Powering autonomous sensor nodes using ambient energy from the local environment (solar micro-cells, thermal gradients, piezoelectric vibration, ambient radio frequency waves), completely eliminating chemical battery replacement and e-waste.
  • Edge Data Aggregation: Filtering and aggregating sensor data locally at the edge gateway before transmission, preventing power-draining radio transmissions of redundant readings.

3. Chapter 1 (+ SDG)
1.1 Reputation as motivation ⭐ PYQ Topic

Three Primary Drivers of Corporate Green Computing:

  1. 1. Doing the Right Thing (Ethics): Fulfilling social and environmental obligations to employees, local communities, and future generations.
  2. 2. Making Money (Marketing & Revenue): Winning customer trust, qualifying for eco-conscious enterprise bids, and expanding market share through proven sustainability credentials.
  3. 3. Saving Money (Finance & Operations): Direct financial savings achieved by lowering power consumption, reducing cooling demands, and extending IT hardware lifecycles.
1.2 Avoiding greenwash ⭐⭐⭐ Top PYQ Favorite

Greenwashing: The deceptive practice of misleading consumers regarding the environmental practices of an organization or the environmental performance of a product.

⭐The Seven Sins of Greenwashing (Exam Must-Know):

  1. 1. Sin of the Hidden Trade-off: Emphasizing a single green attribute (e.g., recycled cardboard box) while concealing massive core environmental damage (e.g., toxic chemical manufacturing and heavy carbon emissions).
  2. 2. Sin of No Proof: Asserting environmental performance without accessible supporting data or third-party certification.
  3. 3. Sin of Vagueness: Using ill-defined buzzwords like "eco-friendly," "green," or "all-natural" that lack standardized, measurable definitions.
  4. 4. Sin of Irrelevance: Advertising compliance with a standard that is already mandated by law for all manufacturers (e.g., claiming "CFC-free" when CFCs are globally banned by treaty).
  5. 5. Sin of Lesser of Two Evils: Promoting an eco-friendly feature on a product category that is inherently harmful to the environment.
  6. 6. Sin of Fibbing: Making claims that are completely false or forged.
  7. 7. Sin of False Labels: Displaying self-created graphics that falsely mimic independent, third-party eco-certification endorsements.

⭐Actionable Rules to Avoid Greenwashing:

  • Never publicize green aspirations in advance before achieving concrete, measurable results.
  • Rely on recognized independent third-party certifications (EPEAT, Energy Star, RoHS, ISO 14001).
  • Publish auditable sustainability data with transparent methodologies and open reporting.
1.3 Social license to operate ⭐⭐ Common in PYQ

Social License to Operate (SLO): The ongoing acceptance, trust, and approval granted by local communities and broader society for an organization to conduct its business activities.

  • SLO vs. Legal License: A legal permit is issued by government authorities; a Social License is informal, unwritten, and must be continually earned through ethical behavior.
  • Ease of Loss: A legal permit remains valid until officially revoked, whereas an SLO can be instantly destroyed by corporate environmental negligence or public scandal.
  • ⭐IT Relevance (Data Centers):
    • Hyperscale data centers draw massive electrical power from local municipal grids and consume regional water supplies for evaporative cooling.
    • Without strong community trust and local benefits, surrounding communities oppose permits, protest facility expansion, and demand strict regulatory limits.
  • Preserving an SLO: Investing in local green jobs, funding local renewable energy projects, and reporting environmental impact with full transparency.
  • Industry Precedents: Tobacco and nuclear power lost public trust and suffered crippling regulatory crackdowns; modern technology firms protect their SLO through carbon-neutral commitments.
1.4 Green computing & your current career ⭐ PYQ Topic

Three Winning Arguments to Justify Green Projects to Executive Management:

  1. 1. Save Money: Quantify clear return on investment (ROI) via lower power utility bills, reduced server counts, and lower cooling overhead.
  2. 2. Reduce Business Risk: Protect the company against future carbon taxes, rising energy prices, and e-waste regulatory fines.
  3. 3. Strategic Sustainability: Align the project with corporate sustainability goals:
    • Led: IT proactively pioneers enterprise-wide green policies.
    • Supported: IT delivers the infrastructure for corporate green goals.
    • Plus: Green benefits delivered as an added bonus alongside primary business performance upgrades.
1.5 Green computing and your department
  • Internal Teams > External Consultants: Internal IT professionals understand institutional workflows, command greater trust from colleagues, and maintain long-term ownership of green practices.
  • IT as the Natural Pioneer: Because information technology touches every workflow across modern corporations, the IT department is uniquely positioned to drive enterprise-wide sustainability.
1.6 Green recruiting and retention ⭐ PYQ Topic

Attracting Top Modern Talent:

  • High-performing university graduates actively evaluate prospective employers based on corporate social responsibility and environmental values.
  • A verifiable green reputation serves as a decisive recruitment advantage in competitive technology hiring.

⭐The Virtuous Talent Retention Cycle:

  1. Proactive green computing practices elevate corporate brand reputation.
  2. High corporate reputation attracts talented, mission-driven employees.
  3. Purpose-driven work increases employee job satisfaction and long-term retention.
  4. Proud employees advocate positively for the company across industry networks.
  5. Positive employee advocacy further magnifies corporate reputation.
1.7 Getting word out inside the company ⭐ PYQ Topic

Seven Proven Internal Communication Channels:

  1. Collaborative Planning: Include cross-departmental stakeholders early in project design.
  2. One-on-One Briefings: Secure executive buy-in through personal leadership meetings.
  3. Targeted Email Updates: Send focused, brief updates to internal team mailing lists.
  4. Company Publications: Highlight energy savings in company newsletters and intranet posts.
  5. Executive ROI Briefings: Deliver concise cost-benefit presentations to finance leaders.
  6. "Lunch and Learn" Workshops: Host informal midday sessions demonstrating practical office energy-saving tips.
  7. Town Hall Celebrations: Publicly celebrate achieved energy reduction milestones at company-wide gatherings.
1.8 Getting word out outside the company ⭐ PYQ Topic
  • Competitor Benchmarking: Analyze the public environmental disclosures of industry peers to identify best practices.
  • Fact-Based Press Releases: Focus on quantitative, verifiable milestones (e.g., 30% reduction in data center power) rather than vague claims.
  • Video News Releases (VNRs): Produce concise (3–5 minute) video case studies showing real hardware upgrades, solar installations, and recycling programs.
SDG ⭐⭐ Common in PYQ

Sustainable Development Goals (SDGs): 17 global goals established by the United Nations (2030 Agenda) addressing global challenges, including poverty, inequality, climate change, and environmental degradation.

⭐Five Core SDGs Directly Driven by Green IT (High Exam Yield):

  • SDG 7 (Affordable and Clean Energy): Powering data centers and cloud computing networks with 100% renewable energy (solar, wind, hydroelectric).
  • SDG 9 (Industry, Innovation, and Infrastructure): Designing energy-efficient data center architectures, adopting edge computing, and modernizing IT infrastructure.
  • SDG 11 (Sustainable Cities and Communities): Deploying Green IoT sensor networks for adaptive street lighting, smart traffic routing, and water leak detection.
  • SDG 12 (Responsible Consumption and Production): Mitigating electronic waste (e-waste) through modular hardware design, equipment reuse, and certified take-back recycling.
  • SDG 13 (Climate Action): Decarbonizing enterprise computing operations and substituting carbon-intensive physical travel with digital collaboration.

4. Chapter 2
2.1 Why saving money is green ⭐⭐ Common in PYQ

The Economic Equation: $\text{Profit} = \text{Revenues} - \text{Costs}$.

  • 100% Bottom-Line Impact: Every dollar saved in IT operational costs flows 100% directly into net corporate profit, whereas an additional dollar of revenue yields only fractional profit margin after costs.
  • Compounding Annual Savings: Once implemented, energy efficiency improvements deliver financial savings year after year.
  • Cost Cutting is Inherently Green: Every business expenditure consumes physical resources, burns electricity, generates waste, and carries a carbon footprint. Cutting waste cuts carbon.
  • ⭐The Concept of Negawatts (Exam Favorite - Fall 2025 Q2):
    • Definition: A theoretical unit of electrical power representing an amount of energy saved through conservation and efficiency rather than generated.
    • Origin & Significance: Coined by energy analyst Amory Lovins; saving one watt of energy (a Negawatt) is vastly cheaper, cleaner, and faster to implement than building new power plants to generate an additional watt of electricity.
2.2 Getting focused on money-saving efforts ⭐ PYQ Topic

Three Predictability Advantages of Cost-Saving Over Revenue-Generating Efforts:

  1. 1. Predictable Implementation Costs: The cost of purchasing energy-efficient hardware or configuring power management software is precise and controllable.
  2. 2. Predictable Financial Returns: Kilowatt-hour savings and utility tariff reductions can be forecasted with high mathematical precision compared to volatile sales forecasts.
  3. 3. Continuous Recurring Payoff: A single energy efficiency project generates cumulative operational savings across every subsequent budget year.
2.3 Implementing energy efficiency ⭐⭐ Common in PYQ

Three Progressive Tiers of IT Energy Efficiency:

  1. Tier 1: Changing How Current Devices Are Used (Behavioral & Software Shift):
    • Power down end-user computers, displays, and printers when not in use.
    • Enforce automated group policies for sleep and hibernate modes after 15 minutes of idle time.
    • Educate employees to build sustainable computing habits.
    • Implement dynamic server load management (spinning down servers during off-peak windows).
  2. Tier 2: Upgrading to More Efficient Devices in the Same Class (Hardware Shift):
    • Replace older servers with models utilizing 80 Plus Platinum power supplies and low-TDP processors.
    • Procure laptops and monitors certified with high Energy Star and EPEAT ratings.
  3. Tier 3: Transitioning to Entirely Different Device Classes (Architecture Shift):
    • Replace power-hungry 250W desktop towers with 30W thin clients, mini PCs, or tablets.
2.5 Moving to cloud services ⭐ PYQ Topic
  • Superior Facility Efficiency: Hyperscale cloud providers operate state-of-the-art data centers with Power Usage Effectiveness (PUE) ratings near 1.1–1.2 (vs. traditional on-premises facilities averaging 1.8–2.0).
  • High Server Utilization: Multi-tenant workload pooling pushes average physical server utilization from 10–15% on-premises up to 65%+ in the cloud.
  • Utility-Scale Green Power: Major cloud providers purchase massive volumes of off-site renewable power (solar and wind power purchase agreements).
  • Is Cloud Always Automatically Green? No—it depends on the specific geographic region's local energy grid mix and whether legacy on-premise servers are properly decommissioned rather than left idling.
  • Financial Shift & Pricing Risk:
    • Converts high upfront capital expenditures (CapEx) into predictable operational expenditures (OpEx).
    • Requires long-term Total Cost of Ownership (TCO) analysis to safeguard against subscription price hikes and unexpected cloud data egress charges.
2.6 Digitalizing non-IT functions ⭐⭐⭐ Top PYQ Favorite

⭐Five Key Non-IT Functions to Digitize (High Exam Yield - Spring 2026 Q4 & Summer 2025 Q2):

  1. 1. Postal Mail & Paper Invoicing $\rightarrow$ Email & Electronic Billing:
    • Eliminates paper production, chemical printing inks, envelopes, and fossil fuel transportation emissions.
    • Dramatically speeds up billing cycles and reduces storage archiving costs.
  2. 2. Physical Checks & Signatures $\rightarrow$ Digital Payments & E-Signatures:
    • Replaces physical trips to the bank, paper checks, and physical courier transit with instant electronic fund transfers and cryptographic e-signatures.
  3. 3. Traditional Fixed Telephony $\rightarrow$ Cloud VoIP & Unified Messaging:
    • Eliminates dedicated copper telephone wiring and specialized PBX hardware boxes by transmitting voice data over existing computer networks.
  4. 4. In-Person Conferences $\rightarrow$ Virtual Teleconferencing:
    • Replaces carbon-heavy long-distance commercial flights, hotel stays, and rental cars with video conferencing collaboration tools.
  5. 5. Daily Office Commuting $\rightarrow$ Remote Work & Telecommuting:
    • Eliminates vehicle exhaust emissions from daily traffic jams.
    • Allows organizations to downsize physical office real estate, slashing facility heating, lighting, and cooling energy.
2.7 Greening your energy-saving moves ⭐ PYQ Topic

Three Categories of Money-Saving Moves:

  1. 1. Saves Money & Highly Green: Actions that cut operational expenses while reducing environmental impact (e.g., virtualizing servers, installing smart thermostat controls, deploying automated PC sleep policies).
  2. 2. Saves Money & Marginally Green: Bulk purchasing agreements that lower shipping package volume and unit purchase costs, but do not reduce the devices' ongoing operational power draw.
  3. 3. Saves Money & Not Green at All: Shifting manufacturing or data operations to regions with loose environmental laws and dirty coal grids, or laying off local staff to increase executive travel.
2.8 Money-saving efforts ⭐ PYQ Topic

Three Strategic Approaches to Cost Optimization:

  1. 1. Stop Doing Stuff (Elimination): Eliminate unnecessary business travel, cancel redundant software licenses, and stop printing hardcopy internal reports.
  2. 2. Do Similar Stuff Differently (Substitution): Replace 250W desktop computers with energy-efficient laptops or tablets; replace physical filing cabinets with secure cloud storage.
  3. 3. Do New Stuff (Transformation): Implement automated digital self-service portals and deploy AI-driven energy optimization models.

3.3 Key roots of environmentalism

The historical evolution of modern environmentalism developed in clear stages:

  1. Conservation (The Starting Point): Preserving natural resources—protecting forests, rivers, wildlife, and creating national parks.
  2. Pollution Awareness: Rising public concern over industrial air, toxic water, and chemical soil pollution.
  3. Species Protection: Enacting legal protections for endangered wildlife and plant species.
  4. Environmental Organizations: Formation of influential global citizen groups and NGOs (e.g., Greenpeace, WWF).
  5. Political Influence: Environmentalism entering government politics and lawmaking (e.g., the Green Party of Germany).
  6. Sustainability Core: Transition to the principle of meeting present needs without compromising future generations.
  7. Climate Change Priority: Global warming emerging as the central, urgent challenge of modern environmentalism.

IT's Dual Role: Information Technology is simultaneously part of the solution and part of the environmental problem.

  • Why IT was seen as green: Enabled paperless digital workflows, virtual teleconferencing, and remote coordination; environmental groups rely heavily on technology (websites, social media, scientific modeling).

3.6 A brief history of the climate

Natural Climate History: Earth's climate has constantly changed over geological epochs:

  • Snowball Earth (650 million years ago): Planet was almost entirely covered in ice.
  • Warm Eras: Earth was once ~10°C warmer with significantly higher sea levels.
  • Ice Ages: Repeated natural cycles of glacial expansion and retreat.
  • Holocene: The stable, warm geological period of the last 12,000 years that enabled human agriculture and civilization.

Why is today's climate change different and dangerous?

  • Unprecedented Speed: Past changes took thousands of years; today's warming occurs in just ~100 years, leaving species and human systems little time to adapt.
  • ⭐Littoral Zones in Danger: Rapid sea level rise directly threatens coastal and delta regions where large human populations live.

Key Geological Terms:

  • Anthropocene: The current unofficial epoch where human activities have become the dominant influence on Earth's climate and ecosystems.
  • Geoengineering: Large-scale technological interventions designed to intentionally alter Earth's climate (e.g., solar radiation management, carbon removal).

Chapter 1 ⭐⭐⭐ Top PYQ Favorite

Parallel System Architectures:

  • Tightly Coupled Systems: Multiprocessors sharing a centralized memory space and operating under a single operating system; low latency, but limited scalability.
  • Loosely Coupled Systems: Distributed compute nodes with private memory connected via network interconnects (clusters and grid networks); high scalability and fault tolerance.

⭐Amdahl's Law (Limits of Parallel Speedup - Exam Favorite):

Speedup ≤ 1 / ( S + (1 − S) / N )
  • Variables: $S$ is the strictly serial fraction of the workload ($0 \le S \le 1$), and $N$ is the number of parallel processing cores.
  • Mathematical Reality: If 20% of an algorithm is serial ($S = 0.20$), the maximum theoretical speedup cannot exceed $1 / 0.20 = 5\times$, even with an infinite number of processors ($N \to \infty$).
  • ⭐Energy & Green Computing Implication: Adding processors to a serial-bound workload consumes extra electrical wattage and produces heavy waste heat with diminishing performance returns, severely ruining energy efficiency.

⭐Key Data Center Energy & Efficiency Metrics:

  • PUE (Power Usage Effectiveness):
    PUE = Total Facility Power / IT Equipment Power
    • Measures overhead energy consumed by cooling, lighting, and power distribution.
    • Ideal benchmark: PUE = 1.0 (100% of facility power feeds computing hardware).
    • Traditional data centers average 1.8–2.0; ultra-green modern data centers achieve 1.1–1.2.
  • CUE (Carbon Usage Effectiveness): $\text{Total CO}_2\text{ Emissions} / \text{IT Equipment Energy}$ ($\text{kg CO}_2\text{/kWh}$).
  • WUE (Water Usage Effectiveness): $\text{Annual Facility Water Consumption} / \text{IT Equipment Energy}$ ($\text{L/kWh}$).

⭐Thermal Management & Data Center Cooling:

  • Hot Aisle / Cold Aisle Containment: Arranging server racks so cold air intake faces the cold aisle and hot exhaust vents into the hot aisle. Physical containment barriers prevent air mixing, reducing cooling energy by 20–30%.
  • Free Cooling (Air/Water Economizers): Using cool outdoor ambient air or water during colder seasons, allowing mechanical chillers to be powered off.
Chapter 5 ⭐⭐⭐ Top PYQ Favorite

⭐Data Temperature Tiering (Hot Data vs. Cold Data):

  • Hot Data: Frequently accessed, mission-critical active data. Stored on high-speed, low-latency, energy-efficient Solid State Drives (SSDs).
  • Cold Data: Infrequently accessed archival records, backups, and historical data. Stored on high-capacity, cost-effective Hard Disk Drives (HDDs) or optical/tape media.

⭐Disk Power States (Fall 2025 Q8b Core):

  1. 1. Active Mode: Spindle motor runs at full speed (7,200–15,000 RPM), read/write heads actively tracking data (~8–10 Watts).
  2. 2. Idle Mode: Platter spins at full operating speed, heads parked in landing zone (~4–6 Watts).
  3. 3. Standby Mode (Spin-Down): Spindle motor stopped, heads parked, interface electronics listening for commands (~0.5–1 Watt). Saves up to 90% power on cold drives.
  4. 4. Sleep Mode: All disk electronics and motor completely powered down (~0.2 Watts); requires system bus reset to wake.

⭐The Energy vs. Reliability Trade-Off (Thermal Cycling & Mechanical Stress):

  • Repeatedly spinning down and spinning up disk drives causes mechanical wear on spindle bearings and motor coils.
  • Power transitions induce rapid thermal expansion and contraction (thermal cycling), accelerating component fatigue and reducing drive lifespan.
  • Green Best Practice: Only spin down drives hosting verified cold data with prolonged idle intervals (hours or days). Never toggle active/idle drives rapidly.

9.1 Why greenhouse gas emissions are important ⭐ PYQ Topic

  • Carbon Footprint Formula:
    Carbon Emissions (kg CO₂) = Energy Consumed (kWh) × Emission Factor (kg CO₂/kWh)

9.7 Reducing emissions I: embodied energy ⭐⭐⭐ Top PYQ Favorite

⭐Embodied Energy Definition (Spring 2025 Q7 Exam Core):

  • The total cumulative energy consumed across a product's entire pre-use lifecycle—including raw material mining, chemical refining, component fabrication, factory assembly, and worldwide shipping.

⭐The Double Environmental Benefit:

  1. Lower Upfront Manufacturing Emissions: Less raw material extraction and fabrication carbon.
  2. Lower Operational Lifetime Emissions: Hardware engineered with lower physical material mass draws significantly less electricity throughout its operational lifespan.

Real-World Example (Device Classes): A modern tablet uses only ⅓ of the embodied energy of a desktop PC and emits 90% fewer operating emissions during daily use.

Strategies to Reduce Embodied Carbon:

  • Extend hardware refresh cycles from 3 years to 5–6 years.
  • Purchase certified refurbished and remanufactured hardware.
  • Deploy low-power thin clients and virtual desktops instead of bulky desktop towers.
9.8 Reducing emissions II: daily energy use (class-15) ⭐⭐⭐ Top PYQ Favorite

⭐Operational Energy Reduction Strategies (Summer 2025 Q5 & Spring 2026 Q8):

  • Automated Power Management: Enforcing centralized sleep/standby policies across all client machines after 15 minutes of inactivity; auto-powering down monitors and peripheral devices.
  • Virtualization Consolidation: Consolidating lightly loaded physical servers to eliminate idle server electricity draw.
  • Off-Peak Workload Scheduling: Scheduling heavy data backups and batch computing during off-peak nighttime grid hours.

9.9 Reducing emissions III: using different sources ⭐ PYQ Topic
  • Greening the Grid Mix: Shifting corporate power contracts from coal-heavy baseload utilities to renewable energy Power Purchase Agreements (PPAs).
  • On-Site Renewable Generation: Installing rooftop solar photovoltaic (PV) arrays on data center and office facilities.
  • Solar Thermal: Harnessing sunlight directly for facility water and building heating without electrical conversion losses.
  • Peak Shaving: Utilizing on-site battery storage during peak demand hours to avoid high utility peak tariffs.
9.10 Reducing emissions IV: supply chain success ⭐ PYQ Topic

⭐The Five-Step Supply Chain Decarbonization Framework:

  1. 1. Cut at Home: Optimize internal IT operations, eliminate zombie servers, and enforce power management inside your own facilities first.
  2. 2. Pocket Outsourcing Savings: Migrate non-core workloads to energy-efficient hyperscale cloud and co-location providers.
  3. 3. Sweat Your Supply Chain: Require upstream hardware vendors and component manufacturers to provide auditable carbon disclosures (Scope 3 accounting).
  4. 4. Consider Non-Use: Challenge whether hardware purchases or travel are necessary at all—prioritize software optimization and digital collaboration.
  5. 5. Repeat & Continuously Improve: Audit results annually, adjust targets against international frameworks, and iterate.
