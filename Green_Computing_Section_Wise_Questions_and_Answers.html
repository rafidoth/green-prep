1. Cloud Computing
Questions [Fall 2025] - Question 6 (5 Marks)

A growing e-commerce company expects a massive increase in web traffic during the holiday season. Rather than buying new physical servers, they rent virtual machines, storage, and networking resources from a cloud provider. They configure the operating systems themselves and scale the resources up or down depending on the load.

Which cloud services model is being used by the company? Mention the key characteristics of this model and explain your logic for choosing this model as your answer. How does adopting this model contribute to green computing and sustainability?

Model Answer (from Notes):

1. Cloud Services Model Identified

  • Model: IaaS (Infrastructure as a Service).
  • Logic for Selection: The company rents raw computing resources (virtual machines, storage, and networking) and configures the operating systems and software stacks themselves, rather than consuming pre-built applications (SaaS) or developer runtime platforms (PaaS).

2. Key Characteristics of IaaS (Section 1.3)

  • Raw Virtualized Infrastructure: Delivers dynamically scalable virtual compute instances, block storage, and network routing.
  • Client Management Responsibility: The cloud provider manages the physical hardware, hypervisors, and data center facilities; the client configures and manages the operating system, middleware, runtime, and software applications.
  • Pay-As-You-Go Utility Billing: Metered charging based strictly on active resource consumption (CPU hours, memory, gigabytes stored).
  • Rapid Elasticity: Compute resources scale up during peak holiday web traffic and instantly scale down when traffic normalizes.

3. How Adopting IaaS Contributes to Green Computing & Sustainability

  • Server Consolidation & High Utilization: Multi-tenant hyperscale data centers run servers at 65%+ capacity, eliminating dozens of underutilized on-premise physical servers running at only 5–15% capacity.
  • Elimination of Over-Provisioning: Renting elastic cloud VMs eliminates the need to purchase physical hardware that sits idle during non-holiday months, slashing embodied manufacturing carbon.
  • Dynamic Off-Peak Power Savings: Virtual machine instances can be automatically terminated during low-traffic hours, cutting electricity draw and data center cooling loads.
  • Superior Cloud Energy Efficiency (PUE): Hyperscale cloud providers achieve efficient PUE ratings (1.1–1.2 vs. 1.8–2.0 on-premises) and procure large-scale renewable power contracts.

2. Architectural Layer Descriptions

  • 1. Core Layer: The high-speed network backbone that switches incoming and outgoing traffic between the data center and the external Internet / WAN with ultra-low latency.
  • 2. Aggregation Layer: The middle tier interconnecting multiple access switches; enforces access control policies, security firewalls, and traffic load balancing.
  • 3. Access Layer (Top-of-Rack / ToR Switches): Direct physical access point installed in each server rack, connecting compute blades and storage arrays to the internal data center network.
Questions [Spring 2026] - Question 1 (5 Marks)

Analyze how virtualization, SOA, web services, and Web 3.0/ mashups work together to enable modern cloud computing platforms. Support your answer with an example of a real-world cloud application.

Model Answer (from Notes):

1. The Four Enabling Technologies (Section 1.2 & 1.6)

  • Virtualization (The Hardware Abstraction Layer):
    • Hypervisors abstract physical CPUs, memory, and storage into isolated, elastic Virtual Machines (VMs).
    • Enables high-density server consolidation and dynamic resource allocation on demand.
  • SOA - Service-Oriented Architecture (The Design Pattern):
    • Structures complex enterprise software into independent, modular, loosely coupled services.
    • Each service delivers a discrete business function that can be independently updated and scaled.
  • Web Services (The Communication Standard):
    • Universal Standard Protocols:
      • REST
      • SOAP
      • XML
      • JSON
    • Enables heterogeneous services running on different operating systems and languages to communicate seamlessly.
  • Web 3.0 & Mashups (The Aggregation & Presentation Layer):
    • Mashup applications combine data and functionality from multiple independent web APIs into a unified user application.
    • Delivers responsive, interactive, and intelligent digital interfaces to end-users.

2. How They Work Together in Modern Cloud Platforms (The Integration Pipeline)

  1. Hardware Foundation: Virtualization pools physical data center hardware into scalable, elastic virtual compute resources.
  2. Software Architecture: SOA organizes enterprise applications into modular, reusable service components hosted on those virtual instances.
  3. Network Interoperability: Web Services provide the standard communication bridge allowing those distributed SOA services to exchange data across cloud networks.
  4. User Experience: Mashups consume those web services via APIs, synthesizing multiple cloud data streams into seamless, rich enterprise web applications.

Questions [Spring 2025] - Question 1 [CO1] (5 Marks)

A tech company releases a new line of laptops branded as "EcoSmart Devices." In its marketing materials, the company claims these laptops are "Environmentally Friendly" and have "Zero Environmental Impact." The promotional content highlights a sleek design with minimal packaging and uses green-themed visuals to reinforce the eco-conscious image. However, a recent investigative report reveals that the laptops are built with non-recyclable materials, the manufacturing process consumes high levels of energy from non-renewable sources, and there is no environmental certification or data to support their claims.

What key issue or practice is being illustrated in this scenario? Identify the misleading elements in the company’s campaign, and discuss the potential consequences of this type of marketing practice for consumers, the environment, and the company itself.

Model Answer (from Notes):

1. Key Issue Identified: Greenwashing (Section 1.2)

  • The scenario illustrates Greenwashing—the deceptive practice of misleading consumers regarding the environmental practices of an organization or the eco-performance of a product.

2. Misleading Elements in the Campaign (The Sins of Greenwashing)

  • Sin of Vagueness: Using sweeping, undefined buzzwords like "Environmentally Friendly" and "Zero Environmental Impact" with zero concrete technical metrics.
  • Sin of No Proof: Asserting absolute environmental claims without providing third-party verification, published audits, or recognized eco-labels.
  • Sin of the Hidden Trade-off: Emphasizing sleek minimalist packaging and green visuals while concealing that the laptops use non-recyclable materials and high-carbon, non-renewable manufacturing.
  • Sin of Fibbing: Claiming "zero impact," which is physically impossible for manufactured electronics containing silicon processors and batteries.

3. Consequences of This Marketing Practice

  • For Consumers: Misleads well-intentioned buyers into paying eco-premiums for dirty products; breeds cynicism and distrust toward genuine green products.
  • For the Environment: Causes ongoing environmental damage, accelerates fossil fuel depletion, and generates non-recyclable toxic e-waste.
  • For the Company: Destroys corporate brand reputation, revokes the company's Social License to Operate (Section 1.3), invites regulatory penalties for false advertising, and repels talented job candidates.

Questions [Fall 2025] - Question 2 (5 Marks)

State the concept of Nega watts. A mid-sized software company operates an office with 300 desktop computers, multiple servers, and networking equipment that run continuously, even during non-working hours. The company has noticed a steady increase in electricity bills and a higher carbon footprint due to inefficient energy usage. Management wants to implement energy-efficient green computing practices without affecting employee productivity.

As an IT manager, identify three energy-efficient green computing measures that can be implemented in the organization. Explain how these measures reduce energy consumption and carbon emissions.

Model Answer (from Notes):

1. The Concept of Negawatts (Section 2.1)

  • Definition: A theoretical unit of electrical power representing an amount of energy saved through conservation and efficiency rather than generated.
  • Origin & Significance: Coined by energy theorist Amory Lovins; saving one watt of energy (a Negawatt) is significantly cheaper, cleaner, and faster to implement than building new power plants to generate an additional watt of electricity.

2. Three Energy-Efficient Measures for the 300-PC Office (Section 2.3)

  • 1. Automated Power Management Policies (Tier 1):
    • Enforce central group policies configuring all 300 desktops and monitors to enter sleep/standby mode after 15 minutes of idle time and fully shut down outside office hours.
    • Impact: Eliminates 14+ hours of nightly idle power draw per PC, cutting office electrical consumption by over 40%.
  • 2. Server Virtualization & Cloud Migration (Tier 1 & 2):
    • Consolidate multiple continuously running on-premise servers into a few dense virtualized servers or migrate to a high-efficiency cloud provider.
    • Impact: Cuts baseline server electricity and 24/7 server room air-conditioning loads.
  • 3. Transition to Thin Clients / Mini PCs (Tier 3):
    • Replace bulky 250W desktop towers with 30W energy-efficient mini PCs or thin clients during the next hardware refresh.
    • Impact: Reduces active hardware wattage by up to 85% without sacrificing worker productivity.

Questions [Fall 2025] - Question 8 (a & b) (Hot/Cold Data & Disk Power State)

Explain the concept of Hot Data and Cold Data. State the impact of disk power state on the storage.

Model Answer (from Notes):

1. Concept of Hot Data and Cold Data (Chapter 5)

  • Hot Data: Frequently accessed, mission-critical active data requiring ultra-low latency and high input/output operations (IOPS). Kept on high-speed, energy-efficient Solid State Drives (SSDs).
  • Cold Data: Infrequently accessed archival records, compliance backups, and historical logs. Kept on cost-effective, high-capacity Hard Disk Drives (HDDs) or optical/tape libraries.

2. Impact of Disk Power States on Storage (Chapter 5)

  1. 1. Active Mode: Spindle motor runs at full speed (7,200–15,000 RPM), heads actively reading/writing (~8–10 Watts).
  2. 2. Idle Mode: Platter spins at full operating speed, heads parked (~4–6 Watts).
  3. 3. Standby Mode (Spin-Down): Spindle motor completely stopped, heads parked, electronics waiting (~0.5–1 Watt). Saves up to 90% power on cold storage!
  4. 4. Sleep Mode: All disk electronics powered down (~0.2 Watts); requires system bus reset.

3. The Energy vs. Reliability Trade-Off (Thermal Cycling)

  • Mechanical & Thermal Stress: Spinning down drives saves massive electricity, but frequent spin-ups create mechanical wear on motor bearings and induce rapid heating/cooling cycles (thermal cycling).
  • Thermal expansion and contraction can shorten drive lifespan. Therefore, spin-down must only target verified cold data with long idle windows (hours or days), never active drives.
